A gentle slope passes and emits a fluid font-size. A pair too steep for 5× zoom is rejected (only a --tw-fl-error is emitted) — see the commented example in the source.

The element-scope caveat

Ranges live in element-level custom properties, so one variant retunes the whole element — but inherits: false stops it leaking to descendants, and two ranges don't compose (last in the cascade wins).

ranged parent (md→lg) · default-range child (does not inherit the parent's range)
one variant retunes this element's padding as well as its text
two ranges on one element — the cascade winner takes the whole element
